 AAS - Accident Alert System

 Vision

AAS (Accident Alert System) is an AI-powered emergency response system that automatically detects road accidents and alerts the nearest hospital with the user's live GPS location.

## Features

-  Live GPS Tracking
-  Automatic Accident Detection
-  Nearest Hospital Alert
-  Emergency Contact Notification
- Google Maps Integration
-  AI-based Accident Prediction
